# Graph Algorithms

This repository contains Python programs for representing graphs and analyzing their structure. The examples use adjacency lists and adjacency matrices, and read graph data from standard input.

## Algorithms included

- Check whether an undirected graph is bipartite using breadth-first search and two-coloring.
- Find a matching in a bipartite graph using augmenting paths.
- Convert adjacency matrices to adjacency lists and adjacency lists to adjacency matrices.
- Traverse graphs with depth-first search and report traversal depths.
- Use breadth-first search to find maximum distances within connected components.
- Count weakly connected components in a directed graph.
- Count strongly connected components using Kosaraju’s algorithm.

## Running a program

Run a script with Python and provide its input through the terminal:

```bash
python3 filename.py
```

Each program may expect a different input format. Check the code for the required format and any sentinel value used to end input.
